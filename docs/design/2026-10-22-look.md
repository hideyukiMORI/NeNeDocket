## 1. 構成

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ ▣ [全件 124][定例 10/22 37][自分の担当 9] ＋   台帳の名前   表|両方|詳細 ? ⚙ ─ □ × │ タイトルバー 40
├────────────────────────────────────────────────────────────────────────────┤
│ [🔍 題名・本文・対応策を検索  Ctrl+F] (未完了 37)(期限超過 5)(担当)(分類)   項目 印刷 [＋課題を追加] │ 道具の行 52
├──────────────────────────────────────────────────────┬─────────────────────┤
│ No   起票日 分類 課題                     担当 期限  優先度 状態   完了日 ┃ 森-2 · IT        ×  │

│ 森-2 10/01 IT   共有フォルダの権限が…（選んでいる行）              ┃ 担当 森  期限 …       │
│ …                                                                    ┃ 課題の詳細 / 原因 / 対応策 │

└────────────────────────────────────────────────────────────────────────────┘
```

- **枠なし。** OS の枠とタイトルバーを消し、帯・窓の操作（最小化・最大化・閉じる）を自前で描く。Snap・影・最小化と最大化のアニメーションは OS のまま（Nib の決定 2 と同じ作り）
- **タブは共有ビュー**（全件・定例・自分の担当 …）。Nib のタブは文書、Docket は 1 つの台帳の見方。タブに件数を添える。選んでいるタブは本文の地と繋がり、下に 2 の橙の線
- **表示の切り替え**（表・両方・詳細）は帯の右。Folio の「一覧・両方・ノート」と同じ形で、選んだ側に橙の下線。隣にヘルプ（?）と台帳の設定（歯車）
- **編集は右の詳細のペイン。** いまの下の編集行と段（本文・参加者・添付・履歴）をやめ、ペインに縦に並べる: 番号と分類 → 題名 → 状態の札 6 つ → 項目（ラベルと値の 2 列）→ 長文（詳細・原因・対応策）→ 履歴。添付と参加者もペインの中
- **表は 1 行か 2 行**（ビューごと）。2 行のとき 2 行目は対応策や原因の要約。長文は「…」で切り、全文はペインで読む
- **定例の帯**: 定例のビューで「前回の定例（日時・打った人）から N か所の変更」と内訳、「変わった行だけ」「今日を基準にする」。変わった行は No の左に橙の点
- **ステータスバー**: 同期の状態・台帳の場所・件数（期限超過は橙）・鍵の案内（Ctrl+P・F1）・自分と役・表示言語

## 3. 色の札

いまの `Palette` は 8 色（background・surface・border・ink・muted・accent・on_accent・selection）。採用案は 14 枚にする。配色 125 は、いまと同じく地・文字・強調の 3 色から整数の補間で導く（ADR 0012）。

| 札 | ダーク（ubuntu-aubergine） | ライト（neutral-light） | 用途 |
| --- | --- | --- | --- |
| `background` | #300A24 | #F4F5F7 | 表の地・選んだタブ |
| `title_bar` | #1E0516 | #E1E4E9 | タブの帯・窓の縁（Nib と同じ） |
| `status` | #26071D | #E9EBEF | ステータスバー |
| `pane` | #2A0820 | #FFFFFF | 詳細のペイン・設定の目次 |
| `line` | #43183A | #E1E4E9 | 行の区切り・面の境 |
| `field` | #3B1430 | #FFFFFF | 入力の欄・Ctrl+P の面・カード |
| `border` | #5A2A4C | #D5D9E0 | 欄とボタンの枠 |
| `text` | #EEEEEC | #1B1F24 | 文字 |
| `muted` | #B8A9B3 | #5C6570 | 見出し・補足・完了の行（灰色で残す） |
| `selection` | #4A1E3D | #FBE3D9 | 選んでいる行 |
| `accent` | #E95420 | #E95420 | 選んだタブと切り替えの下線・主ボタン・期限超過の印・キャレット |
| `accent_text` | #F6B49A | #B23A0F | 地の上の橙の文字（優先度「高」・期限超過・入った札） |
| `check` | #D7C4E5 | #5E2750 | 「確認中」の札（Nib の文字列の色） |
| `synced` | #7CC4A0 | #2F7D57 | 同期した点・「完了」の札の点。**配色ごとに導く**（施主の決定 3） |

`on_accent` は白のまま。`accent_soft`（橙の薄い面）は `accent` の不透明度で描く（ダーク 16%・ライト 10%）。文字の色はどれも地に対して 4.5:1 以上を狙う（`muted` を完了の行に使うのは、`gutter` では足りないため）。

## 4. 部品の状態（`Parts`）

- 行: 通常・ポインタが乗った・選んでいる（`selection`）・編集中（橙の枠とキャレット）・IME の確定前（下線・候補の窓は欄の左下で OS が描く・ADR 0020）・期限超過（`⚠` と `accent_text` の太字）・完了（`muted`）・定例で変化（No の左の橙の点）
- 状態の札 6 つ: 未着手（枠）・対応中（橙の薄い面）・確認中（`check`）・保留（枠・点なし）・完了（`synced` の点）・中止（点のみ）
- ボタン: 主（橙の地）・押している・副（枠）・ポインタが乗った・キーボードで選んだ（橙の枠と 2 の輪）
- 絞り込みの札: 入っている（橙の薄い面）・外れている（枠）
- 期限の略記: `+3` → 2026-10-25（土）。ほかに `10/31`・明日・来週金
- 知らせ（窓の下・ステータスバーの上に 1 行・右に操作）: 書けない（操作は覚えていて繋がったら書く）・他人の変更を上書きした（履歴で選び直す）・並び順が変わった（並べ直す）・期限の形が違う
- 同期の状態（ステータスバーの左）: 同期した（`synced`）・読み直し中（`check`）・共有フォルダを読めない（`accent`・いつから）・書けていない操作 N 件（橙の輪）

## 5. 印刷（`Print`）

A3 横の帳票。題（部署・台帳の名前）・時点・絞り込み・ビュー、**右上に作成・確認・承認の印の欄**（施主の決定 1）。長文は折り返して全部出す。色に頼らない: 期限超過は `⚠` と太字、優先度「高」は太字、定例で変わった行は「●」。下に凡例・出した場所と人・頁。見出しは頁ごとに繰り返す。形式は印刷用 HTML を `OpenerPort` で開く（ADR 0021 の段階 2）。

## 8. まだ

- X11 の枠なしは Windows ほど素直でない（WM が Snap と影を持たないことがある）。施主の WSLg で確かめるまで「動く」と書かない
- 125 の配色で `synced` と `check` と `accent_text` が地に対して読めるかは、導く式を決めてから全配色で測る
- 狭い窓（1,024 以下）でペインをどう畳むかは描いていない
