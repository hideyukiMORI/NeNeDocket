# ADR 0025 — 部品の縁の色を足し、配色から導く色にコントラストの下限を機械で守らせ、フォーカスは外側の輪にする

- 状態: **受理**（Issue #128・施主 2026-11-16「進めて」）
- 日付: 2026-11-16
- Issue: #128
- 影響する規則: ADR 0012（配色の 3 色から 8 色を導く）/ ADR 0022（採用した見た目）/ ARC-001（1 つの経路）/ FR-019 / WCAG 2.2 の 1.4.1・1.4.3・1.4.11・2.4.7・2.4.13

## 文脈

B の後半の設計（[docs/design/2026-11-09-toolbar-and-settings.md](../design/2026-11-09-toolbar-and-settings.md) 第 7 節）でアクセシビリティのペルソナが既定の配色を測り、4 つの不足を挙げた。

| 箇所 | 実測 | 基準 |
| --- | --- | --- |
| 欄・札・チェックの縁 | 約 1.35:1 | 1.4.11（部品の境界）3:1 |
| 選んでいる完了の行（灰色の字 × 選びの面） | 4.46:1 | 1.4.3（文字）4.5:1 |
| 選んでいる行の面 | 地に対して 1.42:1 | 1.4.1（色だけに頼らない） |
| フォーカスと選びの印 | 同じ 1 px の橙 | 2.4.7 / 2.4.13（フォーカスが見える） |

縁の色（`Border`）は表の罫線・区切り線と部品の縁を兼ねている。罫線まで 3:1 にすると表がうるさくなる。配色は 125 あり（ADR 0012）、1 つずつ目で直すことはできない。

## 決定

1. **色の役割に `Control`（部品の縁）を足し、9 つにする。** 欄・ボタン・札・チェック・選択箱の縁は `Control`、罫線・区切り線・スクロールバーの線は今の `Border` のまま
2. **導いた色にコントラストの下限を持たせ、導出が自分で守る**（`theme_derivation`）。百分率は今の表を出発点にし、足りなければ 1 ずつ動かして初めて下限を満たす値を取る
   - `Control` は地と面の両方に 3:1 以上（縁 → 前景へ寄せる）
   - `Selection` はその上の前景（`Ink`）が 4.5:1 以上（強調 → 地へ戻す）
   - `Muted` は地・面・選びの面の 3 つに 4.5:1 以上（前景から離す量を減らす）。`Selection` と一緒に探し、灰色の字が前景から離れたまま取れる最初の組を取る（選びの面を地の側へ戻すことがある・選んだ行は 4 の帯でも分かる）。どの組でも取れない配色では灰色の字は前景と同じになる
3. **比は WCAG 2 の相対輝度を整数で計る**（core の `contrast`）。sRGB の 256 段の線形の値を 10⁷ 倍した表を持つ（浮動小数を使わない・決定的）。テストは浮動小数の式で別に計り、125 の配色の全部で下限を確かめる
4. **選んでいる行は左に強調の 3 px の帯**（色の面だけに頼らない）
5. **フォーカスは外側 2 px の強調の輪**（縁の外 1〜2 px）。選んでいる札の縁（強調の 1 px）とは形で見分ける。欄・ボタン・札・チェック・選択箱・タブで同じ

## 帰結

- 得たもの: どの配色を選んでも、部品の縁・灰色の字・選びの面の上の字が基準を満たす。新しい配色（利用者のテーマファイル・ADR 0012 の 7）を足しても同じ導出が守る
- 125 の配色のうち、灰色の字が前景と同じになるのは solarized-dark だけ（前景そのものが地に対して 4.5:1 をわずかに越えるだけで、離す余地が無い）。この配色では完了の行と案内の字が前景と同じ色になる
- 失ったもの: 配色の見え方が少し変わる（縁が濃く、灰色の字が濃く、一部の配色で選びの面が淡く）。nene-nib の `derive_ui` と同じ形ではなくなる（下限の調整が増える）
- 設定・ジャーナル・スナップショットの形は変えない。UI（X11・Windows）は `Paint` を色の表で引くだけなので、新しい役割は表が増えるだけ

## 検討した案

| 案 | 却下の理由 |
| --- | --- |
| `Border` をそのまま 3:1 にする | 表の罫線も濃くなり、行の多い表が格子に見える。罫線は部品の境界ではないので 1.4.11 の対象でもない |
| 百分率の表を配色ごとに手で決める | 125 の配色を目で直すことになり、足した配色で崩れる。機械で守らせる原則（ADR 0001）に反する |
| フォーカスの縁を太くする（内側） | 選んだ札の縁と同じ場所・同じ色で、太さだけの違いになる（2.4.13 は面積と比で見る）。外側の輪の方が形で分かる |
| 比の計算を浮動小数で | core は浮動小数を使わない（決定性・ADR 0012）。256 段の表で足りる |
